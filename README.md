# repolocally

A tiny practice repository created locally first and then pushed to GitHub, used to learn how local and remote Git repositories connect, including resolving a merge conflict.

## Contents

| File | Purpose |
|---|---|
| `test.html` | Minimal HTML page that shows "Hello world!" |
| `new.php` | Minimal PHP script that prints "Hello World!" |

## Running the examples

Open `test.html` in a browser, or run the PHP file:

```
php new.php
```

This repo is a Git exercise, not an application.
